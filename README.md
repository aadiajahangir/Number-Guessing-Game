# 🎯 Number Guessing Game

A beginner-friendly Number Guessing Game built with Python.

## 📌 About the Project

This is one of my first Python projects, created to strengthen my understanding of Python fundamentals through hands-on practice.

The program generates a random number, and the player has to guess it. The game provides feedback based on each guess until the correct number is found.

## 🛠️ Concepts Practiced

- Variables and data types
- User input
- Conditional statements (`if`, `elif`, `else`)
- `while` loops
- Random number generation
- Basic program logic

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Clone this repository.
3. Open the project folder in VS Code or another Python editor.
4. Run the Python file.
